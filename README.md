# HealthLife

HealthLife 是一个面向手机端的个人健康追踪工具，用于记录运动、饮食、睡眠和体重，并通过周／月趋势帮助用户观察生活习惯。

项目采用本地优先方式，不提供账号、服务端存储或自动同步。正式页面将通过 GitHub Pages 发布，首次加载后规划支持 PWA 离线使用。

## 当前状态

MVP 功能与 PWA 发布资源已经完成。当前页面支持五类记录、周／月日历补录、连续记录、最近 7 天／30 天趋势、完整 JSON 备份恢复，以及首次在线加载后的离线访问；远端推送和 GitHub Pages 公开发布仍待单独确认。

## 本地数据边界

- 正式数据将保存在当前浏览器的 `localStorage` 中，不上传到 GitHub。
- 不同设备、浏览器、普通模式和无痕模式使用不同的数据空间。
- 清除网站数据、卸载浏览器或更换设备可能导致记录丢失。
- “数据”入口支持导出完整 JSON 备份；更换设备、浏览器或清理网站数据前，应先保存最新备份。
- 仓库中的测试和演示内容必须完全虚构，不得提交真实健康记录。
- 本项目只提供个人记录和趋势观察，不提供医疗诊断或治疗建议。

## MVP 范围

- 运动：类型、时长、强度和备注。
- 饮食：餐次、文字描述、健康程度、饱腹感和备注，不计算卡路里。
- 睡眠：入睡时间、起床时间、睡眠质量、夜醒次数和备注。
- 体重：每日体重、可选体脂率和 7 日移动平均。
- 饮水：每日饮水总量。

正式页面规划为“今日、趋势、记录”三个一级入口，设置和数据管理集中在独立入口中。

## 当前使用方式

1. 启动本地静态服务器，打开 `docs/index.html` 对应地址。
2. 在“今日”使用默认周日历选择日期，或展开整月补录历史记录；精确日期输入仍可使用。
3. 点击运动、饮食、睡眠、体重或饮水卡片进行记录。日历会展示每天已完成的记录类别数。
4. 睡眠、体重和饮水每天各保留一条，已有记录时入口会直接进入编辑。
5. 在“记录”按日期倒序查看全部数据，并进行编辑或删除；删除后 10 秒内可以撤销。
6. 在页面顶部“数据”入口导出完整 JSON 备份；导入时先查看摘要，再确认完整替换当前数据。
7. 刷新页面后，记录会从当前浏览器的 `localStorage` 恢复。

使用支持 PWA 的浏览器首次在线完整打开页面后，可通过浏览器菜单“添加到主屏幕”或“安装应用”。Service Worker 会缓存当前版本的应用外壳；发布新版本时必须同步提升 `docs/sw.js` 中的缓存版本，旧缓存会在新版激活后清理。

“连续记录”按每天至少存在一类记录计算。如果今天尚未记录，会保留截至昨天的连续天数；补记今天后自动延长。

“趋势”支持最近 7 天和最近 30 天两个自然日窗口：体重展示原始样本和 7 日均重，睡眠展示时长与质量，运动展示次数、时长和类型，饮食展示有记录天数与主观评分，饮水只使用有记录日期计算日均值。所有指标都显示样本量，不构成健康诊断。

页面检测到无法解析的本地数据时会停止写入，并允许下载原始内容，避免静默覆盖。

导入会严格校验备份格式、schema 版本、字段范围和记录唯一性。覆盖非空本地数据前，页面会先触发当前完整数据的安全备份；写入失败时不会切换到导入数据。仓库中的 `test-data/healthlife-demo-v1.json` 仅包含虚构演示记录。

## 项目结构

```text
docs/           GitHub Pages 页面与浏览器端模块
tests/          Node.js 标准库测试
test-data/      纯虚构演示数据及其说明
AGENTS.md       项目开发规范
DATA_MODEL.md   schema v1 字段与统计口径
ROADMAP.md      项目真实进度
```

## 本地验证

项目不依赖第三方运行时包。安装 Node.js 后直接运行：

```bash
npm run check
npm test
```

也可以不使用 npm：

```bash
node --check docs/model.js
node --test tests/*.test.js
```

启动本地页面：

```bash
python3 -m http.server 8000 --directory docs
```

然后访问 `http://localhost:8000/`。
