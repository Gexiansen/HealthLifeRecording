# HealthLife

HealthLife 是一个面向手机端的个人健康追踪工具，用于记录运动、按克称重的饮食、睡眠和体重，并通过周／月趋势帮助用户观察生活习惯与营养摄入。

项目采用本地优先方式，不提供账号、服务端存储或自动同步。正式页面规划通过 GitHub Pages 发布，首次在线加载后支持 PWA 离线使用。

## 当前状态

MVP、移动端交互优化和 PWA 发布资源已经完成。当前正在实施饮食营养追踪：按食物和克数记录，自动计算热量、蛋白质、脂肪和碳水化合物，并支持自定义食品、自制菜谱、精确／估算模式和分析型 JSON 导出。

## 本地数据边界

- 正式数据将保存在当前浏览器的 `localStorage` 中，不上传到 GitHub。
- 饮食营养功能使用独立的 schema v2 存储；旧 schema v1 数据不会读取、迁移或删除。
- 不同设备、浏览器、普通模式和无痕模式使用不同的数据空间。
- 清除网站数据、卸载浏览器或更换设备可能导致记录丢失。
- “数据”入口支持导出完整 JSON 备份；更换设备、浏览器或清理网站数据前，应先保存最新备份。
- 仓库中的测试和演示内容必须完全虚构，不得提交真实健康记录。
- 本项目只提供个人记录和趋势观察，不提供医疗诊断或治疗建议。

## 当前记录范围

- 运动：类型、时长、强度和备注。
- 饮食：餐次、食物、克数、记录模式、估算可信度、备注，以及自动计算的热量、蛋白质、脂肪和碳水化合物。
- 睡眠：入睡时间、起床时间、睡眠质量、夜醒次数和备注。
- 体重：每日体重、可选体脂率和 7 日移动平均。
- 饮水：每日饮水总量。

正式页面规划为“今日、趋势、记录”三个一级入口，设置和数据管理集中在独立入口中。

## 当前使用方式

1. 启动本地静态服务器，打开 `docs/index.html` 对应地址。
2. 在“今日”使用默认周日历选择日期，或展开整月补录历史记录。
3. 点击运动、饮食、睡眠、体重或饮水入口进行记录；运动可快捷选择时长，饮水可在今日页直接增加 250 ml 或 500 ml。
4. 饮食优先选择“精确称重”，逐项选择食物并输入克数；外卖、堂食或旅行时可选择“估算记录”，并标注中／低可信度。
5. 包装食品可按营养标签创建自定义食品；批量做饭可按原料克数建立菜谱，再填写成品总重量，食用时只需记录实际吃掉的成品克数。
6. 食物加入一餐后会保存当时的营养快照，后续修改自定义食品或菜谱不会改变历史记录。
7. 主观评分同时显示文字语义和底层分值；睡眠会实时预览时长，并按起床日期归档。
8. 睡眠、体重和饮水每天各保留一条，已有记录时入口会直接进入编辑。
9. 在“记录”按类型和月份筛选全部数据；删除收纳在“更多”中，执行后 10 秒内可以撤销。
10. 在页面顶部“数据”入口可导出完整备份或分析型 JSON；完整备份用于恢复，分析型 JSON 用于交给分析工具查看饮食、睡眠、运动和体重趋势。
11. 刷新页面后，记录会从当前浏览器的 `localStorage` 恢复。

使用支持 PWA 的浏览器首次在线完整打开页面后，可通过“数据”入口或浏览器菜单安装应用。Service Worker 会缓存当前版本的应用外壳；检测到新版时页面会提示立即刷新。发布新版本时必须同步提升 `docs/sw.js` 中的缓存版本，旧缓存会在新版激活后清理。

“连续记录”按每天至少存在一类记录计算。如果今天尚未记录，会保留截至昨天的连续天数；补记今天后自动延长。

“趋势”支持最近 7 天和最近 30 天两个自然日窗口：体重展示可查看详情的原始样本和 7 日均重，睡眠展示时长与质量，运动展示次数、时长和类型，饮食展示有记录天数、日均宏量营养素和精确／估算记录数，饮水只使用有记录日期计算日均值。存在等长上一周期样本时会显示差值；所有指标都显示样本量，不构成健康诊断。

内置食物营养值参考 [USDA FoodData Central](https://fdc.nal.usda.gov/) 的每 100 克数据，用于快速估算。真实数值会因品牌、部位、烹调方式和含水量变化；包装食品应优先录入标签值，无法称重的外食应使用估算模式，避免把估算结果误认为精确摄入。

页面检测到无法解析的本地数据时会停止写入，并允许下载原始内容，避免静默覆盖。

导入会严格校验备份格式、schema 版本、字段范围和记录唯一性。覆盖非空本地数据前，页面会先触发当前完整数据的安全备份；写入失败时不会切换到导入数据。仓库中的 `test-data/healthlife-demo-v2.json` 仅包含虚构演示记录。

## 项目结构

```text
docs/           GitHub Pages 页面与浏览器端模块
tests/          Node.js 标准库测试
test-data/      纯虚构演示数据及其说明
AGENTS.md       项目开发规范
DATA_MODEL.md   schema v2 字段与统计口径
ROADMAP.md      项目真实进度
```

## 本地验证

项目不依赖第三方运行时包。安装 Node.js 后直接运行：

```bash
npm run check
npm test
```

也可以不使用 npm：

```bash
node --check docs/*.js
node --test tests/*.test.js
```

启动本地页面：

```bash
python3 -m http.server 8000 --directory docs
```

然后访问 `http://localhost:8000/`。

## 发布

正式页面位于 `docs/`。推送远端和将 GitHub Pages 发布源设置为 `main` 分支的 `/docs` 目录属于公开发布操作，需要单独确认。
